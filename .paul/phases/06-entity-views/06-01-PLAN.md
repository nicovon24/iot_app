<objective>
## Goal
`/devices` and `/assets` show real, live data from the backend (`GET /devices`/`GET /assets`) in a themed table, replacing the `ComingSoon` placeholders from Phase 5. Each row links toward an entity detail route (built in 06-02/06-03).

## Purpose
This is the first real content in the app shell built in Phase 5 — proves the whole stack (auth → apiClient → TanStack Query → UI) end-to-end with real ThingsBoard-backed data, and establishes the reusable list-table pattern Phase 6's remaining plans (and Phase 7) build on.

## Output
- `frontend/src/hooks/useEntities.ts`: TanStack Query hook wrapping `apiClient.get` for `GET /devices` or `GET /assets`, with pagination/search params
- `frontend/src/widgets/EntityListWidget.tsx`: reusable HeroUI `Table`-based widget rendering a `PageData<EntityRef>`, themed to match the dark-navy/electric-blue shell
- `frontend/src/app/devices/page.tsx` and `frontend/src/app/assets/page.tsx`: real pages using the hook + widget instead of `ComingSoon`
</objective>
