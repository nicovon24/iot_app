<objective>
## Goal
Remove `POST /devices` entirely. Devices remain listable/readable (`GET /devices`, `GET /devices/:id`) but can no longer be created through this backend.

## Purpose
User decision: rather than extending bare Device creation with the same Customer/hierarchy-linking rules being added to Assets in this same phase (see 4.3-03), Device creation is pulled out of scope entirely until a real Device-to-Asset linking design exists (already tracked as a deferred V2 item in STATE.md/ROADMAP.md).

## Output
- `DevicesController` no longer has a `create`/`POST` handler
- `CreateDeviceDto` deleted
- `EntitiesService.createDevice` deleted (dead code, no other callers)
</objective>
