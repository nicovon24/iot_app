### Auto-fixed Issues

**1. [Bug] `assignAssetToCustomer` called a non-existent TB endpoint**
- **Found during:** Task 3 verification (AC-1 curl sequence)
- **Issue:** `POST /api/customer/{customerId}/asset/{assetId}` returned 404 ("No static resource ...") — that endpoint doesn't exist on this ThingsBoard Cloud PE instance
- **Fix:** Changed to `POST /api/owner/CUSTOMER/{customerId}/ASSET/{assetId}`, the PE owner-reassignment API (same family already used for `parentCustomerId` per Phase 2.2 decisions)
- **Files:** `backend/src/entities/entities.service.ts`
- **Verification:** Direct curl to both endpoints against the real TB Cloud API confirmed the old one 404s and the new one works; re-ran the full AC-1/AC-2 sequence successfully after the fix
- **Side effect verified as correct behavior, not a new bug:** the failed first attempt triggered the compensating rollback (`deleteAsset`), which is exactly what AC-5 requires — so this bug incidentally produced a real, unplanned AC-5 verification
