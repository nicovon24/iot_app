# 9.2-02 Summary

## Status: Complete

## What was built
- `backend/src/users/users.service.ts`: `toEntityRef()` now sets `additionalInfo: { appRole:
  user.additionalInfo?.appRole ?? null }` on every returned `EntityRef`, so `GET /users` and the
  `create` response both expose each user's role.
- `frontend/src/hooks/useUsers.ts` (new): `useUsers(customerId)`, `useCreateUser()`,
  `useDeleteUser()` — same TanStack Query pattern as `useCustomers.ts`.
- `frontend/src/widgets/forms/CreateUserDialog.tsx` (new): email/password/role form (react-hook-
  form + zod), `Dialog`/`Select` primitives, `toastSuccess`/`ApiError` pattern matching
  `ClientWizard`.
- `frontend/src/app/users/page.tsx` (new): Client picker (`Select` fed by `useCustomers()`), a
  simple row list of that Client's users (email + role badge + Delete via `ConfirmDialog`), Add
  button opening `CreateUserDialog`. Deliberately does not reuse `EntityListWidget` (its
  type-based icon logic doesn't fit a User row, per the plan's own boundary).
- `frontend/src/lib/nav-items.ts`: `Users` nav item's `comingSoon: true` removed.
