<objective>
## Goal
A sysadmin can manage `admin`/`reader` Customer Users from the frontend: pick a Customer, see its users with their role, add a new one, delete an existing one. The backend `users` module (Phase 2.2-02) already supports create/list/delete — only the UI and a small role-visibility gap are missing.

## Purpose
Closes the "Tenant/sysadmin can manage users from the frontend" requirement from Phase 9.2's CONTEXT.md. The `Users` nav item already exists (`frontend/src/lib/nav-items.ts`, currently `comingSoon: true`) — this plan makes it real, following the same nav-placeholder-to-real-page pattern every other Phase 5 nav item already went through.

## Output
- `GET /users?customerId=` now returns each user's `appRole` (currently dropped)
- New `/users` page: Customer picker + user list (email, role) + Add User dialog + Delete
- `Users` nav item flips from `comingSoon: true` to active
</objective>

<acceptance_criteria>

## AC-1: Users list shows each user's role
```gherkin
Given a sysadmin session on /users with a Customer selected
When the page loads that Customer's users
Then each row shows the user's email and its role (ADMIN or READER), not just the email
```

## AC-2: Creating a user
```gherkin
Given a sysadmin on /users with a Customer selected
When they submit the Add User form (email, password, role, using the selected Customer)
Then a new Customer User is created in ThingsBoard and the list refreshes to include it
```

## AC-3: Deleting a user
```gherkin
Given a sysadmin viewing a user row on /users
When they click Delete and confirm
Then the user is deleted in ThingsBoard and disappears from the list
```

## AC-4: Non-sysadmin gets a real 403, not a fake client-side block
```gherkin
Given a non-sysadmin session reaches /users (no client-side role gating exists anywhere in this app, per established Phase 7 precedent)
When they submit the Add User form or click Delete
Then the backend's existing RolesGuard/@Roles('SYSADMIN') returns a real 403, surfaced via the existing ApiError → toastError pattern
```
