<objective>
## Goal
Land the visual-design foundation for Phase 9.1: replace the dark-navy/electric-blue token set with a light glassmorphic purple/indigo one (per the user's reference mockup), remove dark mode entirely, restyle the sidebar rail + app shell to the new gradient/glass look, and rebuild the Login screen as a split-screen layout — with zero behavior changes to auth, nav, or routing.

## Purpose
This is the first of three 9.1 plans. Every later screen restyle (dashboard, list/admin screens) depends on the tokens and `.glass-card`/gradient utilities this plan defines — doing it first avoids every subsequent plan re-deriving its own ad hoc colors.

## Output
- `globals.css` rewritten to a single light-only token set (no `:root.dark` block) plus new glass-card/gradient/fadeUp utilities
- Inter font wired in as the app's font-family
- Dark-mode toggle removed from the UI and code (`useTheme.ts` deleted)
- `Sidebar.tsx`/`AppLayout.tsx` restyled to the dark-gradient rail + light `#eef0f6` app background
- `login/page.tsx` rebuilt as split-screen (glass-card form left, accent-gradient decorative panel right)
</objective>
