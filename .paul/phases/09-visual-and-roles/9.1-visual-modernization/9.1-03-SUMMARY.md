# 9.1-03 Summary: Shared dialogs, Admin panel, entity detail tabs, Alarms page

## What shipped

**Task 1 — Shared Dialog/Select/ConfirmDialog/EditEntityDialog/AddAssetModal**
- `Dialog.tsx`: content wrapper now `.glass-card` (dropped the redundant `rounded-2xl border border-border bg-surface-card shadow-2xl`) — cascades to every consumer (Admin's Add/Assign dialogs, EditEntityDialog, ConfirmDialog, ClientWizard).
- `Select.tsx`: dropdown/menu surface restyled to `.glass-card` (trigger button untouched, stays a normal bordered input).
- `ConfirmDialog.tsx`: no changes needed — it's a destructive (Delete) action, kept its red button per the plan's explicit "don't gradient destructive actions" rule; it inherits the glass surface from `Dialog.tsx` automatically.
- `EditEntityDialog.tsx`, `AddAssetModal.tsx`: primary Save/Create buttons changed from `bg-accent` to `background: var(--gradient-accent)` (inline style). `AddAssetModal` (a HeroUI `Modal`, not the shared `Dialog`) got its own `classNames.base` changed to `.glass-card` directly.
- No prop-interface changes to any of these five components.

**Task 2 — Admin Miller-column panel**
- `AdminAssetPanel.tsx`, `AdminDevicePanel.tsx`, `AdminClientsColumn.tsx`: outer column wrapper → `.glass-card`; "+ Add"/"+ Assign" buttons changed from bordered buttons to small accent-colored text links (`color: var(--gradient-accent-from)`, `hover:underline`); `Spinner` loading branches replaced with `<TableRowsSkeleton rows={3} columns={2} />` (matches each panel's 2-column NAME/ACTIONS shape).
- `app/admin/page.tsx`: no changes needed — it has no direct card-wrapper styling of its own, just lays out the column components.
- All CRUD hooks (`useCreateAsset`, `useDeleteAsset`, `usePatchAsset`, `useLinkDevice`/`useUnlinkDevice`, `useDeleteCustomer`) and dialog wiring left untouched.

**Task 3 — Entity detail tabs + global Alarms page**
- `app/entities/[id]/page.tsx`: confirmed the Map tab (`<Tab key="map">`) via its existing `isDisabled={!hasLocation}` pattern and left it completely untouched. Restyled the tab underline (`cursor` classNames slot) from `bg-accent` to an inline gradient (`bg-[linear-gradient(135deg,var(--gradient-accent-from),var(--gradient-accent-to))]`, since HeroUI's `classNames` slots only accept Tailwind classes, not a `style` prop); added `animate-fade-up` to the `panel` slot so each tab's content fades in on switch; telemetry-key `<select>` background changed `bg-surface-card` → `bg-white/80` (same contrast fix as Login's inputs).
- `AttributesTableWidget.tsx`, `ValueTileWidget.tsx`, `LineChartWidget.tsx`: all `border-border bg-surface-card` wrappers (including per-scope empty-state boxes in `AttributesTableWidget`) changed to `.glass-card`. Left `Spinner` loading state and all Recharts/attribute-grouping logic untouched — skeleton loaders were explicitly scoped to `CountTileWidget`/`EntityListWidget`/`AlarmsListWidget` in 9.1-02, not these three.
- `app/alarms/page.tsx`: filter-controls container (`Severity`/`Status` selects) changed to `.glass-card`; the `AlarmsListWidget` below it already picked up its own glass-card/skeleton/empty-state restyle from 9.1-02.
