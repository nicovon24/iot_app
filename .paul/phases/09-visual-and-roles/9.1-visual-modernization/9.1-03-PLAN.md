<objective>
## Goal
Finish Phase 9.1 by carrying the glass-card/gradient look from 9.1-01/02 into the remaining screens: shared modal/dialog components (used by every "Add"/"Edit"/"Confirm" flow app-wide), the Admin hierarchy panel's Miller columns, the entity detail page's Attributes/Telemetry/Alarms tabs, and the global Alarms page. The Devices/Assets/Clients list pages need no direct changes — they already inherit `EntityListWidget`'s new look from 9.1-02.

## Purpose
Closes out the "restyle every screen except the map-based ones" requirement from CONTEXT.md. Shared components (Dialog, Select) are done first in this plan so every consumer (Admin panel, Add Asset modal, Edit dialogs, Client wizard) picks up the new look without being individually touched for its dialog chrome.

## Output
- `Dialog.tsx`/`Select.tsx` restyled to glass (backdrop-blur surface, accent-gradient primary actions) — cascades to every modal in the app
- `ConfirmDialog.tsx`, `EditEntityDialog.tsx`, `AddAssetModal.tsx` primary-button restyle to the accent gradient
- Admin panel (`AdminAssetPanel`, `AdminDevicePanel`, `AdminClientsColumn`, `app/admin/page.tsx`) restyled: glass-card columns, "+ Add" as an accent-colored text link, skeleton loading via `TableRowsSkeleton`, centered muted empty states
- Entity detail page (Attributes/Telemetry/Alarms tabs) and the global Alarms page restyled to glass cards — Map tab untouched
</objective>
